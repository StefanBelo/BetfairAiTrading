### Key Insights from Strategy Builder Research

**Finding #1: Template UI Wins**
- Fastest to market: 2-3 weeks vs 8-10 weeks for full hybrid
- Highest adoption: 60-70% of users vs 20-30% for visual only
- Lowest cost: $5-10k vs $30-40k for full solution
- **Industry trend**: Coinrule, Koinly (template-based) fastest growing platforms

**Finding #2: Your Competitive Assets**
- 113 strategy templates + 9 control flow strategies = near-infinite composability
- Betting-specific focus (not stocks)
- Real Betfair integration
- Optional AI suggestions (unique differentiator)

**Finding #3: Implementation Sequence**
- **Phase 1**: Template UI with forms-based builder (2-3 weeks)
- **Phase 2**: AI chat suggestions for strategy recommendations (2-3 weeks)
- **Phase 3**: Visual drag-drop node builder (3-4 weeks)
- **Phase 4**: Community features and marketplace (3-4 weeks)

**Finding #4: Why Not Pure AI?**
- Non-deterministic (same input ≠ same output)
- Cost scales with usage ($3-100/month LLM fees)
- Hallucination risks (AI might suggest impossible compositions)
- Privacy concerns (data to 3rd party)
- Not suitable for time-critical trading (2-5s latency)

## 🎓 Key Insights & Lessons Learned

### Discovery #1: Feature Completeness
BFExplorer has **80% of requested features already built**. The roadmap is enhancement/visibility, not new construction.

### Discovery #2: F# Studio as Differentiator
The integrated F# IDE with live Betfair market data is **undermarketed and underutilized**. This is a genuine competitive advantage not found in competitors like OddsChecker, Betfair native app, or Flumine.

### Discovery #3: Risk Management Architecture
**Session-level controls exist** (Execute Till Target Profit, Trailing Stop Loss). The gap is **account-level daily caps and position limits**, not fundamental risk management.

### Discovery #4: Community Engagement
Reddit community (/r/BetfairAiTrading) has moderate activity but creator maintains it actively. Opportunity for growth with proper marketing.

### Discovery #5: Developer Experience
C# MCP integration has known issues (from conversation context), but F# Studio provides professional alternative. Python wrapper libraries exist in ecosystem but not official.
