## 🎓 Key Concepts Explained

### Strategy Template
A pre-configured strategy type (e.g., "Place Bet") with parameters you fill in

### Control Flow Strategy
A way to compose strategies (sequence, conditional, loop, parallel)

### MCP (Model Context Protocol)
The protocol Bfexplorer uses to expose tools to AI agents

### Data Context
Available data sources for decision-making (e.g., WeightOfMoneyData)

### Composability
Ability to combine multiple strategies into complex workflows

### Non-determinism
Same input doesn't always produce same output (problem with AI)

## 💡 Critical Insights

1. **Users prefer simplicity**: Template UI beats code for 90% of users
2. **Composition is powerful**: 113 templates + 9 control flows = unlimited variations
3. **TradingView is complex**: Most traders never learn Pine Script
4. **Templates are winning**: Coinrule, Koinly growing fastest (template-based)
5. **AI is risky for trading**: Hallucinations dangerous, LLM cost problematic
6. **Hybrid works best**: Combine simple UI + optional AI suggestions

## ❓ FAQ

**Q: Do we need visual builder from the start?**  
A: No. Template UI alone gets 60-70% adoption. Add visual builder later if demanded.

**Q: Should we use AI for strategy building?**  
A: As optional enhancement (suggestions), not core. Too risky & expensive.

**Q: How long to build Template UI?**
