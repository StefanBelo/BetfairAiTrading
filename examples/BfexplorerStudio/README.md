# BfexplorerStudio Examples

This folder contains sample scripts and notebooks for working with Bfexplorer and Betfair APIs in F# and C#.
## F# Script Files (.fsx)

- **BetfairApiGettingStarted.fsx**: Loads Betfair and Bfexplorer assemblies, demonstrates querying Betfair event types and market data from F#.
- **BfexplorerBotGettingStarted.fsx**: Shows how to define and run a custom Bfexplorer bot with parameterized strategy logic.
- **BfexplorerBotTriggerGettingStarted.fsx**: Demonstrates implementing a bot trigger to report turnover per minute for a market selection.
- **BfexplorerGettingStarted.fsx**: Loads Bfexplorer dependencies and provides helper functions to display market, bets, and running bots.
- **BfexplorerServiceGettingStarted.fsx**: End-to-end example of logging in, retrieving account funds, getting the active market, and updating market data using asyncFlow for robust error handling.

## C# Script Files (.csx)

- **BfexplorerServiceGettingStarted.csx**: C# version of the Bfexplorer service workflow, including login, account funds retrieval, and market data access.

## Verso Notebook Files (.verso)

- **BetfairApiGettingStarted.verso**: Notebook for Betfair API setup and querying event types/markets in F#.
- **BfexplorerBotGettingStarted.verso**: Notebook for configuring and running a Bfexplorer bot sample.
- **BfexplorerBotTriggerGettingStarted.verso**: Notebook for implementing and testing a bot trigger in F#.
- **BfexplorerGettingStarted.verso**: Notebook for loading Bfexplorer dependencies and helper functions.
- **BfexplorerServiceGettingStarted.verso**: Notebook for Bfexplorer service login, account funds, and market data retrieval in F#.
- **BfexplorerServiceGettingStartedCS.verso**: C# notebook for Bfexplorer service login and market data.
- **DataContextForMarket.verso**: Notebook for initializing and accessing market data context APIs.
- **DataContextForMarketSelection.verso**: Notebook for working with selection-level data context APIs.
- **MyTestChart.verso**: Example notebook for creating and displaying a chart from F# data.
- **TestChart.verso**: Notebook for plotting data using F# and charting libraries.
- **TestChartPlotly.verso**: Notebook for generating interactive charts with Plotly.NET in F#.
